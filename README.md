**Web Scraping Using Python**

**Project Overview**
This project extracts book data from websites using Python web scraping techniques and stores the data in a structured format for further analysis.

**Skills Demonstrated**

- Python
- Web Scraping
- Data Collection
- Data Cleaning
- Data Analysis
- Data Export

**Tools Used**

- Python
- BeautifulSoup
- Requests
- Pandas
- Jupyter Notebook
**Features**

- Extracted book information from web pages
- Parsed HTML content using BeautifulSoup
- Collected and stored data in CSV format
- Cleaned and structured scraped data

**Files Included**

- webscrapping.ipynb
- books_data.csv
- data.csv
- htmls folder
- README.md

**Project Outcome**
Developed an automated web scraping solution to collect, clean, and organize website data for analysis and reporting purposes.
